Ⅳ. 최적화 교과서 p.167~171

경사하강법 점화식과 갱신 손계산 집중 훈련

접선의 기울기와 보폭을 결합하여 최솟값을 귀납적으로 찾아가는 수치 연산 과정을 체계화합니다.

🤔 3차시를 여는 질문

"곡선의 경사에 보폭을 곱해 빼주기만 하면, 손실함수의 최솟값을 갖는 지점에 도달할 수 있을까?"

$a_{n+1} = a_n - \eta L'(a_n)$

알고리즘의 점화식을 바탕으로, 직접 수치를 계산하며 수열이 최적값으로 수렴해 가는 원리 를 검증합니다.

🎯 오늘의 학습 목표

목표 1 · 점화식의 구조적 해석

경사하강법 점화식 $a_{n+1} = a_n - \eta L'(a_n)$ 의 각 항의 수학적 의미를 해석하고, 부호 결정 원리 를 설명할 수 있다.

목표 2 · 2회 반복 손계산 및 감속 원리 도출

주어진 이차 손실함수 모델에서 1~2회 반복 갱신 수치를 정확히 손계산 하고, 보폭이 저절로 줄어드는 자동 감속 메커니즘 을 도출할 수 있다.

공식 분석 교과서 p.167~168

경사하강법 점화식: 한 걸음의 이동을 결정하는 수식

현재 위치 $a_n$ 에서 접선의 기울기와 학습률의 곱을 빼서 다음 위치 $a_{n+1}$ 을 귀납적으로 결정합니다.

📐 공식 구조 요소 분석

$\mathbf{\color{#38bdf8}{a_{n+1}}} = \mathbf{a_n} \mathbf{\color{#f87171}{-}} \mathbf{\color{#fbbf24}{\eta}} \cdot \mathbf{\color{#4ade80}{L'(a_n)}}$
  • $a_n$ : 현재 단계의 매개변수 값 (출발 지점)
  • $L'(a_n)$ : 현재 점에서의 미분계수(접선의 기울기)
  • $-$ (마이너스): 접선의 기울기와 반대 방향 으로 이동시키는 부호
  • $\eta$ (에타, 또는 $k$ ): 한 번에 이동할 보폭을 결정하는 양의 상수 (학습률)
  • $a_{n+1}$ : 갱신된 다음 단계의 매개변수 값 (도착 지점)

🔄 알고리즘과 수학의 연결

인공지능의 매개변수 갱신 과정은 고등학교 『대수』의 수열의 귀납적 정의(점화식) 와 대응됩니다.

알고리즘 순서도와의 대응

① 초깃값 $a_0$ 설정 $\rightarrow$ 수열의 첫째항
② $a_{n+1} = a_n - \eta L'(a_n)$ 반복 $\rightarrow$ 이웃하는 두 항 사이의 관계식(점화식)
③ $|L'(a_n)| < \epsilon$ 종료 판단 $\rightarrow$ 수열의 수렴 판정

※ 카드를 터치하면 교과서 p.168 순서도와 점화식의 구조적 일치 과정을 상세히 확인할 수 있습니다.

계산 클리닉 교과서 p.168~169

부호 충돌 클리닉: 마이너스와 음수 기울기가 만날 때

접선의 기울기가 음수일 때 공식의 마이너스 부호와 결합하는 계산 과정을 주의 깊게 점검합니다.

⚠️ 자주 발생하는 부호 계산 오류

상황: $a_n = 2$, $\eta = 0.1$, 접선의 기울기 $L'(a_n) = -4$ 일 때

[오류 풀이]
$a_{n+1} = 2 - 0.1 \times 4 = 1.6 \quad \color{#f87171}{\text{(음수 부호 누락)}}$
$\implies$ 반대 방향으로 이동하여 손실함수의 값이 증가함
  • 공식의 뺄셈 기호($-$)와 미분계수 자체의 음의 부호($-$)를 중복으로 고려하지 않아 발생하는 오류입니다.
  • 기울기가 음수이면 손실함수가 최소가 되는 지점은 현재 점보다 오른쪽 에 있으므로 $a$ 의 값은 증가해야 합니다.

💊 바른 계산 절차: 괄호 표기법

음수 기울기 대입 시 반드시 괄호 $( )$ 를 사용하는 규칙을 적용합니다.

[바른 계산 절차]
$a_{n+1} = a_n - \eta \cdot \mathbf{\big( L'(a_n) \big)}$
$\phantom{a_{n+1}} = 2 - 0.1 \times \mathbf{(-4)} = 2 \mathbf{\color{#4ade80}{+ 0.4}} = \mathbf{2.4}$
부호 계산 원칙:
$L'(a_n) < 0 \implies - \eta (- \text{기울기}) = \mathbf{+ \eta |\text{기울기}|}$
$\implies$ 마이너스와 음수가 곱해져 결과적으로 우측(+)으로 이동 합니다.
손계산 훈련 1단계 교과서 p.169 함께하기 3 연계

표준 모델 1단계: 초깃값에서 1회 갱신값 산출하기

손실함수를 미분하여 도함수를 구하고, 초깃값을 대입하여 첫 번째 갱신 좌표 $a_1$ 을 계산합니다.

📝 문제 조건 및 도함수 산출

지필평가 예제 모델

$L(a) = a^2 - 6a + 10$

초깃값: $\mathbf{a_0 = 7}$  |  학습률: $\mathbf{\eta = 0.1}$

  • 손실함수의 최솟값 위치(대칭축): $a = -\frac{-6}{2(1)} = \mathbf{3}$ 에서 최솟값 발생.
  • 일차도함수(미분계수 식):
    $L'(a) = 2a - 6$
  • 현재 위치 $a_0 = 7$ 은 대칭축 $3$ 의 오른쪽에 위치함.

✏️ 1회 갱신 ($a_0 \rightarrow a_1$) 단계별 풀이

  • Step 1 · 접선의 기울기 계산:
    $L'(a_0) = L'(7) = 2(7) - 6 = \mathbf{+8}$
    $\implies$ 기울기가 양수이므로 왼쪽(음의 방향)으로 이동해야 함을 지시
  • Step 2 · 경사하강법 점화식 대입:
    $a_1 = a_0 - \eta L'(a_0) = 7 - 0.1 \times (+8)$
  • Step 3 · 첫 번째 갱신값 산출:
    $a_1 = 7 - 0.8 = \mathbf{6.2}$
검증: 초깃값 $7.0$ 에서 최적점 $3.0$ 을 향해 $0.8$ 만큼 거리가 단축 되었습니다.
손계산 훈련 2단계 교과서 p.169~170

표준 모델 2단계: 연속 2회 갱신과 수렴 궤적 관찰

1회 갱신된 값 $a_1=6.2$ 를 새로운 출발점으로 삼아 2회 갱신값 $a_2$ 를 계산하고 궤적을 확인합니다.

🔢 2회 갱신 ($a_1 \rightarrow a_2$) 손계산

  • Step 1 · 새로운 위치에서의 기울기 계산:
    $L'(a_1) = L'(6.2) = 2(6.2) - 6 = 12.4 - 6 = \mathbf{+6.4}$
  • Step 2 · 점화식 2회차 대입:
    $a_2 = a_1 - \eta L'(a_1) = 6.2 - 0.1 \times (+6.4)$
  • Step 3 · 두 번째 갱신값 산출:
    $a_2 = 6.2 - 0.64 = \mathbf{5.56}$
최적점 $a=3$ 과의 거리 변화:
$a_0(7.0) \rightarrow \mathbf{4.0}$ 차이  |  $a_1(6.2) \rightarrow \mathbf{3.2}$ 차이  |  $a_2(5.56) \rightarrow \mathbf{2.56}$ 차이

📉 매개변수 축($x$ 축) 상의 이동 궤적

갱신이 진행될수록 점들이 최솟값의 위치($a=3$)를 향해 좁혀지는 과정을 수직선 위에서 확인할 수 있습니다.

$a_0 = 7.00$
$\downarrow \quad \mathbf{\Delta a_0 = -0.80}$ (1회 이동량)
$a_1 = 6.20$
$\downarrow \quad \mathbf{\Delta a_1 = -0.64}$ (2회 이동량)
$a_2 = 5.56$
$\dots \rightarrow \mathbf{[ \text{목표 바닥 } a = 3.00 ]}$

💡 이동 거리(보폭)가 $0.80 \rightarrow 0.64$ 로 스스로 감소하고 있습니다.

핵심 원리 교과서 p.170 지식 Plus

경사하강법의 자가 조절: 바닥에 다가갈수록 저절로 멈춘다

학습률이 일정하더라도 미분계수의 절댓값이 작아짐에 따라 이동 거리가 자연스럽게 감속됩니다.

📊 미분계수의 크기 감소 추적

각 스텝에서 계산된 기울기와 실제 이동 보폭의 변화입니다.

단계 ($n$) 위치 ($a_n$) 기울기 ($L'(a_n)$) 실제 이동량 ($|\Delta a|$)
$0$ $7.00$ $8.0$ $0.80$
$1$ $6.20$ $6.4$ $0.64$
$2$ $5.56$ $5.12$ $0.512$

손실함수가 최소인 지점에 가까워질수록 곡선의 경사가 완만해져 $|L'(a_n)| \rightarrow 0$ 이 됩니다.

🛡️ 알고리즘 수렴의 안정성

  • 수학적 원리:
    $\text{이동량 } \Delta a = -\eta \cdot L'(a_n)$
    $\eta$ 는 고정된 상수이지만, $L'(a_n)$ 의 절댓값이 0에 수렴 하므로 이동량 자체가 자연스럽게 축소됩니다.
  • 알고리즘의 안정성:
    만약 일정한 보폭으로만 이동한다면 최솟값 지점 주변에서 진동할 수 있으나, 미분계수에 비례하여 이동하면 최솟값 근처에서 이동량이 미세해져 안정적으로 안착 합니다.
교과서 결론: 경사하강법은 손실함수의 최솟값을 직접 구하기 어려운 복잡한 모델에서도 반복 연산을 통해 최적의 매개변수를 근사적으로 찾아냅니다.

✅ 3차시 핵심 요약

  • 점화식 구조:
    $a_{n+1} = a_n - \eta L'(a_n)$ (현재 위치 $-$ 보폭비율 $\times$ 접선의 기울기).
  • 부호 계산 원칙:
    기울기가 음수($L' < 0$)이면 마이너스와 음수가 곱해져 결과적으로 우측(+)으로 이동.
  • 자동 감속 메커니즘:
    손실함수의 최솟값에 근접할수록 기울기가 $0$ 에 수렴하여 이동 보폭이 스스로 줄어듦.

🚀 4차시 탐구 예고: 학습률의 조절

"학습률 $\eta$ 의 크기에 따라 어떤 현상이 일어날까?"

• $\eta$ 가 너무 작을 때: 최적점에 도달하기까지 지나치게 많은 연산 단계가 소요됨.
• $\eta$ 가 너무 클 때: 최솟값 지점을 지나쳐 진동하거나 최적화 과정이 발산함!
