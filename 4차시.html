Ⅳ-2. 최적화 | 교과서 p.172

학습률 거동 분석 및 최적화 종합 문제 해결

경사의 반대 방향으로 이동하더라도, 학습률의 크기에 따라 최적화의 수렴 여부가 결정됩니다.

💡 생각 열기: 학습률의 필요성 개념 도입

"접선의 기울기 부호와 반대 방향($-L'(a)$) 으로 이동하더라도, 학습률($k$) 이 부적절하면 왜 최적화가 원활하게 이루어지지 않을까?"

• 이전 차시에서 우리는 경사하강법 점화식 $a_{n+1} = a_n - k L'(a_n)$ 을 통하여 매개변수 갱신 과정을 다루었습니다.

• 학습률 $k$ 의 값이 지나치게 크면 최솟값을 지나쳐 진동하거나 발산하고, 지나치게 작으면 최적점에 도달하기까지 과도한 갱신 횟수와 계산 시간이 소요됩니다.

🔍 초매개변수(Hyperparameter) 의 개념: 모델이 데이터로부터 스스로 갱신하는 매개변수와 달리, 사용자가 사전에 직접 설정해야 하는 비례상수를 학습률이라 합니다.
🎯 4차시 핵심 학습 목표 성취 기준

1. 학습률 $k$ 의 크기에 따른 3대 거동 분석
• 과대, 과소, 적정 학습률에 따른 손실함수의 수렴, 지연, 진동 및 발산 거동을 시각적이고 수학적으로 설명할 수 있다.

2. 교과서 대표 문항 및 심화 문제 해결
• 미분계수 측정 데이터로부터 최적값을 추론하는 문항과 부등식을 만족하는 학습률 조건을 대수적으로 해결할 수 있다.

3. 최적화 단원의 종합적 이해
• 최적점의 필요조건($L'(a)=0$) 과 다변수 모델로의 확장을 이해하고 최적화 단원을 완결한다.

공학 도구 탐구 활동 | 교과서 p.172~173

학습률 크기별 3대 거동 비교 시뮬레이터

매개변수 갱신에 따른 점 $(a_n, L(a_n))$ 은 손실함수 곡선 $y = L(a)$ 위를 이동합니다.

📊 3가지 거동의 수학적 특성 교과서 핵심

1. 지나치게 작은 학습률 ($k = 0.02$) — 수렴 지연
• 매 갱신마다 매개변수의 변화량이 너무 작아, 최적점에 도달하기까지 매우 많은 계산 횟수가 요구됩니다.

2. 적절한 학습률 ($k = 0.20$) — 안정적 수렴
• 최적점에 가까워질수록 $|L'(a)|$ 가 감소하여 보폭이 자동으로 줄어들며, 안정적으로 최솟값에 도달합니다.

3. 지나치게 큰 학습률 ($k = 0.85$) — 뚜렷한 좌우 진동 (Oscillation)
• 매개변수의 변화량이 과도하여 최적점($a^* = 2.0$) 을 건너뛰며 반대편 언덕으로 튕겨 나가는 왕복 진동 궤적이 발생합니다.

🔍 상세 설명: 모델이 스스로 조절하지 못하는 초매개변수 학습률의 특성을 확인합니다.

교과서 모델 $L(a) = 2a^2 - a + 4$ 수치 검증

학습률 $k$ 의 값이 클 때 발생하는 진동 현상을 점화식 계산을 통해 분석합니다.

📝 손실함수 및 도함수 산출 Step 1

• 손실함수: $L(a) = 2a^2 - a + 4$

• 도함수(미분계수 식): $L'(a) = 4a - 1$

• 최적점(필요조건): $L'(a) = 0 \iff 4a - 1 = 0 \iff \mathbf{a^* = 0.25}$

• 초깃값: $a_0 = 0$

경사하강법 점화식:
$$a_{n+1} = a_n - k(4a_n - 1)$$
⚡ 학습률 $k = 0.4$ 적용 시 수열의 변화 Step 2 (진동 관찰)

• 0회차: $a_0 = 0 \implies L'(0) = -1$

• 1회차: $a_1 = 0 - 0.4(-1) = \mathbf{0.400}$ (최적값 $0.25$ 초과 이동)

• 2회차: $L'(0.4) = 4(0.4)-1 = +0.60 \implies a_2 = \mathbf{0.160}$

• 3회차: $L'(0.16) = -0.36 \implies a_3 = \mathbf{0.304}$

🔍 매개변수의 값이 $0 \to 0.400 \to 0.160 \to 0.304$ 로 최적값 $0.25$ 의 좌우를 교차하며 수렴하는 진동(Oscillation) 현상이 나타납니다.

미분계수의 부호를 통한 기하학적 판별법과 도함수 일차식 복원법을 함께 학습합니다.

최적의 예측 모델 $f(x)=ax$ 를 구하고자 한다. 손실함수 $L(a)$ 의 미분계수 $L'(a)$ 의 값을 측정한 결과가 다음 표와 같다.

$a$ $1.8$ $2.0$ $2.2$ $2.5$
$L'(a)$ $-6$ $-2$ $2$ $8$

문항: 손실함수 $L(a)$ 를 최소로 만드는 $a$ 의 값을 $m$ 이라 할 때, $10m$ 의 값을 구하시오. (단, $10m$ 은 자연수이다.)

📐 해법 1: 교과서 기하학적 풀이 부호 판별법

1단계: 포물선 개형과 접선 기울기 확인
• 손실함수 $L(a)$ 는 아래로 볼록한 이차함수 포물선입니다.

2단계: 최솟값 $m$ 의 위치 범위 한정
• $a=1.8, 2.0$ 에서 $L'(a) < 0$ $\implies$ 최솟값은 오른쪽에 위치 ($m > 2.0$)
• $a=2.2, 2.5$ 에서 $L'(a) > 0$ $\implies$ 최솟값은 왼쪽에 위치 ($m < 2.2$)

3단계: 자연수 조건으로 최종값 확정
• $2.0 < m < 2.2 \iff 20 < 10m < 22 \implies \mathbf{10m = 21 \implies m = 2.1}$

1회 갱신 범위 조건을 만족하는 학습률 판별

경사하강법 갱신 식과 일차부등식을 연계하여 학습률의 조건을 도출합니다.

📋 교과서 원본 문항 p.175 발전

손실함수 $L(a) = a^2 - 4a + 5$ 에 대하여 $a$ 의 초깃값 $a_0 = 10$ 을 학습을 위한 식

$$a_1 = a_0 - k L'(a_0)$$

을 이용하여 $1$ 회 갱신한 $a$ 의 값을 $a_1$ 이라 하자.

문항: 부등식 $\mathbf{-2 < a_1 < 6}$ 을 만족하는 학습률 $k$ 에 대하여 $20k$ 의 값으로 가능한 자연수의 개수 를 구하시오.

✏️ 단계별 부등식 대수 풀이 풀이 과정

1단계: 도함수 및 1회차 미분계수 산출
• $L'(a) = 2a - 4 \implies L'(a_0) = L'(10) = 2(10) - 4 = \mathbf{16}$

2단계: 1회 갱신 값 $a_1$ 표현
• $a_1 = a_0 - k L'(a_0) = \mathbf{10 - 16k}$

3단계: 부등식 연립 및 $20k$ 의 자연수 개수 판정
• $-2 < 10 - 16k < 6 \iff \mathbf{\dfrac{1}{4} < k < \dfrac{3}{4}}$
• 각 변에 20을 곱하면: $\mathbf{5 < 20k < 15}$
• 가능한 자연수: $6, 7, 8, 9, 10, 11, 12, 13, 14$ $\implies$ 총 9개

Q1. $L'(a) = 0$ 이면 손실함수는 항상 최솟값을 갖는다?
❌ 거짓 터치하여 해설 확인
• 해설: 일반 함수에서는 극댓값이나 변곡점일 수 있습니다. 단, 교과서의 손실함수는 아래로 볼록한 이차함수 이므로 $L'(a) = 0$ 인 지점이 유일한 최솟값이 됩니다.
Q2. 학습률 $k$ 의 값은 작을수록 항상 이상적이다?
❌ 거짓 터치하여 해설 확인
• 해설: 학습률이 지나치게 작으면 최적점에 도달하기까지 과도한 갱신 횟수와 시간이 소요되며, 복잡한 함수에서는 국소 최솟값(Local Minimum)에 안착하여 멈출 위험이 있습니다.
Q3. 갱신을 반복하여 최적점에 접근할수록 매회 이동하는 보폭은 감소한다?
⭕ 참 터치하여 해설 확인
• 해설: 1회 이동 거리 $|a_{n+1} - a_n| = k |L'(a_n)|$ 이므로, 최적점에 가까워져 접선의 기울기 크기 $|L'(a_n)|$ 이 줄어들면 보폭 또한 스스로 줄어듭니다.
Q4. 매개변수가 최적점($L'=0$)에 도달하면 점화식에 의한 갱신은 스스로 정지한다?
⭕ 참 터치하여 해설 확인
• 해설: $L'(a^*) = 0$ 이므로 점화식에 대입하면 $a_{n+1} = a_n - k \cdot 0 = a_n$ 이 되어, 추가적인 이동 없이 현재 매개변수 값이 유지됩니다.

등비수열의 공비 수렴 조건과 학습률 임계값

손실함수 $L(a) = A a^2 + \dots$ 에서 진동과 발산이 일어나는 수학적 조건을 유도합니다.

📐 점화식의 등비수열 변형 대수 증명

이차 손실함수 $L(a) = A a^2 + Ba + C$ ($A > 0$)의 최적점을 $a^*$ 라 하면:

$$L'(a) = 2Aa + B = 2A(a - a^*)$$ 경사하강법 식에 대입하면: $$a_{n+1} = a_n - k \cdot 2A(a_n - a^*)$$ 양변에서 $a^*$ 를 빼면 오차 수열 $e_n = a_n - a^*$ 에 대한 점화식이 유도됩니다: $$a_{n+1} - a^* = \mathbf{(1 - 2Ak)}(a_n - a^*)$$

• 최적점과의 오차 수열 $e_n$ 은 공비가 $r = 1 - 2Ak$ 인 등비수열 을 이룹니다.

🎯 수렴 임계값 판정 ($|r| < 1$) 공비별 거동

등비수열이 $0$ 으로 수렴하기 위한 필요충분조건은 $|r| < 1$ 입니다.

$$-1 < 1 - 2Ak < 1 \iff 0 < 2Ak < 2 \iff \mathbf{0 < k < \frac{1}{A}}$$

• $0 < k < \dfrac{1}{2A}$ ($0 < r < 1$): 진동 없는 단조 수렴

• $\dfrac{1}{2A} < k < \dfrac{1}{A}$ ($-1 < r < 0$): 좌우 진동하며 감쇠 수렴

• $k \ge \dfrac{1}{A}$ ($r \le -1$): 진동하며 발산

[부록 2: 심화 탐구] 딥러닝 최적화 연결

다변수 최적화: 편미분과 그레이디언트 벡터

추세선 $f(x) = ax + b$ 및 다층 신경망으로의 확장을 위한 수학적 도구입니다.

🌐 다변수 모델과 편미분 편미분의 도입

• 기울기 $a$ 와 $y$ 절편 $b$ 를 모두 갖는 모델 $f(x) = ax + b$ 에서는 손실함수 $L(a, b)$ 의 독립변수가 2개가 됩니다.

• 각 변수 방향의 순간변화율을 독립적으로 구하기 위해 편미분(Partial Derivative) 을 적용합니다:

$$\frac{\partial L}{\partial a}, \quad \frac{\partial L}{\partial b}$$

• 편미분 성분을 모은 벡터를 그레이디언트 벡터(Gradient Vector, $\nabla L$) 라 합니다.

🚀 다변수 경사하강법 점화식 일반형 공식

매개변수 벡터를 $\mathbf{w} = (a, b)^T$ 라 할 때 다변수 경사하강법 공식은 다음과 같습니다:

$$\mathbf{w}_{n+1} = \mathbf{w}_n - \eta \nabla L(\mathbf{w}_n)$$

• 일변수 공식 $a_{n+1} = a_n - k L'(a_n)$ 의 직접적인 벡터 확장입니다.

• 딥러닝 신경망의 오차 역전파(Backpropagation) 알고리즘 또한 이 원리를 바탕으로 작동합니다.

🔍 초매개변수(Hyperparameter) 의 수학적 정의

• 매개변수 (Parameter, $a$): 데이터에 의해 경사하강법 알고리즘이 스스로 값을 갱신해 나가는 대상입니다.

• 초매개변수 (Hyperparameter, $k$): 알고리즘이 스스로 결정하지 못하며, 사용자가 학습 전에 외부에서 직접 설정해야 하는 상수입니다.

• 학습률이 지나치게 크거나 작으면 수학적 알고리즘의 유효성과 무관하게 실제 연산 과정에서 수렴에 도달하지 못합니다.

🔍 교과서 p.172 지도 TIP: 학습률의 공학적 의미

• 교과서에서는 학습률 $k$ 를 "파라미터를 조절하는 비례상수로서 보폭(발걸음 폭)을 결정하는 역할" 로 정의합니다.

• 실제 인공지능 모델 훈련에서는 $0.001 \sim 0.01$ 수준의 값을 초깃값으로 설정하여 점진적으로 조절합니다.

• 과대 학습률의 영향: 단순히 수렴 속도가 느려지는 것이 아니라, 최솟값을 지나쳐 반대편으로 넘어가며 손실함수 값이 증가하는 발산(Divergence) 현상을 유발합니다.

🔍 해법 2: 대수적 일차도함수 복원 풀이

[일차도함수 복원 및 방정식 풀이]

• 예측 모델이 $f(x)=ax$ 일 때 손실함수 $L(a) = \frac{1}{n}\sum (y_i - ax_i)^2$ 은 $a$ 에 대한 최고차항이 양수인 이차함수입니다.

• 따라서 도함수 $L'(a)$ 는 반드시 일차식 $pa + q$ 꼴입니다.

• 표의 두 점 $(1.8, -6)$ 과 $(2.0, -2)$ 를 대입하여 기울기 $p$ 를 구하면:

$$p = \frac{-2 - (-6)}{2.0 - 1.8} = \frac{4}{0.2} = 20$$

• $L'(2.0) = 20(2.0) + q = -2 \implies 40 + q = -2 \implies q = -42$

• 복원된 도함수: $\mathbf{L'(a) = 20a - 42}$

• 최적 조건 $L'(m) = 0$ 을 적용하면:

$$20m - 42 = 0 \implies m = \frac{42}{20} = 2.1 \implies \mathbf{10m = 21}$$

• 교과서의 기하학적 부호 판별 풀이 결과($m = 2.1$) 와 완벽히 일치함을 확인할 수 있습니다.

• 손실함수: $L(a) = a^2 - 4a + 5$

• 도함수 산출: $L'(a) = 2a - 4$ 이므로 초깃값 $a_0 = 10$ 에서의 미분계수는 $L'(10) = 2(10) - 4 = 16$ 입니다.

• 경사하강법 1회 갱신:

$$a_1 = a_0 - k L'(a_0) = 10 - 16k$$

• 조건 부등식 대입:

$$-2 < 10 - 16k < 6$$ 각 변에서 $10$ 을 빼면: $$-12 < -16k < -4$$ 각 변을 $-16$ 으로 나누면 부등호 방향이 바뀌므로: $$\frac{4}{16} < k < \frac{12}{16} \iff \mathbf{\frac{1}{4} < k < \frac{3}{4}}$$

• $20k$ 의 값의 범위 산출:

  각 변에 $20$ 을 곱하면: $20 \times \dfrac{1}{4} < 20k < 20 \times \dfrac{3}{4} \iff \mathbf{5 < 20k < 15}$

• 결론: $5$ 와 $15$ 사이의 자연수는 $6, 7, 8, 9, 10, 11, 12, 13, 14$ 로 총 9개 입니다.

🔍 심화: 2차 곡률과 학습률 한계값의 관계

• 손실함수 $L(a) = A a^2 + \dots$ 에서 2차 계수 $A$ 는 곡선의 곡률(가파른 정도)을 결정합니다.

• 공비 $r = 1 - 2Ak$ 에서 수렴 임계값은 $\mathbf{k_{\text{max}} = \dfrac{1}{A}}$ 입니다.

• 곡선이 가파를수록($A$ 가 클수록) 동일한 보폭에 대해 반대편으로 넘어가기 쉬우므로, 안정적인 수렴을 위해 허용되는 최대 학습률 $k_{\text{max}}$ 은 반비례하여 작아집니다.

🔍 심화: 다변수 최적화와 역전파(Backpropagation)

• 다층 인공신경망은 복합적인 합성함수 구조로 설계되어 있습니다.

• 출력층에서 계산된 오차를 바탕으로 각 가중치에 대한 편미분을 구하기 위해 미분의 연쇄법칙(Chain Rule) 을 활용하며, 이를 역전파 알고리즘 이라 합니다.

• 계산된 편미분 벡터($\nabla L$) 는 본 단원에서 다룬 경사하강법 점화식 $\mathbf{w} \leftarrow \mathbf{w} - \eta \nabla L$ 에 대입되어 일괄적으로 매개변수를 갱신합니다.
