## 4단원 추천 탐구 주제
> 1. 교과서 132 ~ 137쪽은 통계적 확률과 조건부 확률을 통한 예측을 다루고 있다. 즉, 현재 관찰된 하나의 정적인 상태의 분류를 다룬다.
> 그렇다면 시간의 흐름에 따라 변하는 상태를 예측할 때는? 마르코프 체인에 대해서 조사해보세요.
---
> 2. 손실함수와 같이 오차의 제곱의 평균을 이용하여 추세선을 구하는 방식은 가우스의 '최소제곱법'에 기반을 두고 있으며, 인공지능이 모델의 예측값과 실제 정답 사이의 오차를 최소화하도록 가중치를 조정하는 기계학습의 기본 원리가 됩니다.
> 가우스가 관측 후 사라진 소행성 '세레스(Ceres)'를 재발견하는 데 기여한 역사적 배경을 조사해 보세요.
> 가우스가 불완전한 소수의 관측 데이터로부터 궤도를 복원하기 위해 '최소제곱법'을 비롯해 어떤 수학적 기법들을 활용했는지 구체적으로 탐구해 보세요.
